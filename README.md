# IAM Portfolio

Hands-on Identity and Access Management (IAM) labs by Quest Bokwe. B.S. Cybersecurity student at West Virginia University, CompTIA Security+ certified, targeting entry-level IAM Analyst roles.

All labs use a personal test tenant and fake users. No employer or client data is included.
